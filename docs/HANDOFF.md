## Conventions and gotchas

- `npx tsc --noEmit` must stay clean (delete `.next/types` first if it references removed routes). `npx eslint src` is also expected clean. `eslint-disable` comments for `react-hooks/exhaustive-deps` are NOT allowed (rule not configured; the comment itself errors).
- Never import `allCurriculums` directly in UI code; use `src/lib/curriculum/registry.ts` (`useCurriculum()`, `getCurriculum()`, `findTopic()`, `searchCurriculum()`).
- Long files: write them whole; Python patch scripts use `io.open(..., encoding='utf-8')` (cp1252 issues on Windows).
- Tests run against `npm run dev` on port 3000 and the `DATABASE_URL` in `.env.local`; e2e accounts must get a pass via `scripts/lib/pass.mjs` (`grantPass`) because there is no trial.
- Commits use identity "Evolw <townsfattakapp@hotmail.com>", end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`; PRs merged with `gh pr merge --merge`; Vercel auto-deploys `main` (if it skips, `npx vercel promote <preview-url> --yes`).
